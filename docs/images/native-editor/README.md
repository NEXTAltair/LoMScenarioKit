# エディターの操作画面

2026-10-27にLinux/X11で起動したLoMScenarioKitを撮影。日本語UIと同梱サンプル「裏山でひと休み」を使用しています。

| 画像 | 撮影した状態 |
|---|---|
| `start-menu.png` | ファイルメニューを開いた状態 |
| `dialogue.png` | 11番の台詞を表示して、プレビューが入力を待っている状態 |
| `choices.png` | 8番の選択肢を表示し、最初の選択肢にポインターを置いた状態 |

リポジトリの説明書と、5言語の内蔵ヘルプで同じ画像を使います。内蔵ヘルプにはPNGを埋め込み、配布版の文書には`docs/`ごとコピーします。更新時は実際の操作画面を撮り直し、ファイル名・画像サイズ・説明文を合わせてください。

プレビュー内の立ち絵・背景・会話UIは『活俠傳』のゲーム画像です。ゲーム画像の権利は元の権利者に帰属し、本プロジェクトのライセンス対象には含まれません。ここにある画像は操作説明用のスクリーンショットです。
