# エディターの操作画面

2026-10-27にLinux/X11で起動したLoMScenarioKitを撮影。日本語UIと同梱サンプル「裏山でひと休み」を使い、実際に編集・再生・保存・開き直しを行った画面です。

| 画像 | 操作・確認内容 |
|---|---|
| `01-open-sample.png` | サンプルを開くメニュー |
| `02-sample-open.png` | 初回のサンプル表示（画像の抽出前） |
| `03-extract-menu.png` | 画像抽出のメニュー |
| `04-game-folder.png` | Mortal_Dataを含むゲームフォルダーの選択 |
| `05-extraction-progress.png` | 抽出の進捗 |
| `06-assets-ready.png` | 抽出後の背景表示 |
| `07-select-dialogue.png` | 05番の台詞を選択 |
| `08-edited-dialogue.png` | 本文をHello!へ変更 |
| `09-rewind.png` | 先頭に戻る |
| `10-playing.png` | 再生してHello!で待機 |
| `11-next-dialogue.png` | 次の台詞へ進む |
| `12-choose-training.png` | 一緒に稽古するを選択 |
| `13-branch-result.png` | 11番の台詞へ分岐 |

| `17-reopened.png` | 開き直したコピーにHello!が残る |
| `18-node-review.png` | ノード編集欄で判定・コメントを追加し、保存 |

リポジトリの説明書と5言語の内蔵ヘルプで同じ17枚を使います。操作箇所が読める範囲を撮影し、内蔵ヘルプではクリックで拡大できます。PNGは実行ファイルに埋め込み、配布版の文書には`docs/`ごとコピーします。

`18-node-review.png`は2026-10-28にLinux/X11の独立した確認用画面で撮影し、リポジトリの説明書に追加しました。サンプルのコピーで05番を選び、要修正の判定とコメントを付けて保存しています。実際のクリック・キー入力で操作し、保存データも確認しました。ノード設定とフロー図を併せて表示するため、コメント欄の高さを広げています。

`04-game-folder.png`と`16-recent-project.png`は画像編集ツールで個人のパスと不要なフォルダー名を黒塗りしました。未加工の画像は同梱しません。ほかの画像も、タイトルバー・保存先・通知に個人の情報が入っていないか確認してから更新してください。

プレビュー内の立ち絵・背景・会話UIは『活俠傳』のゲーム画像です。ゲーム画像の権利は元の権利者に帰属し、本プロジェクトのライセンス対象には含まれません。ここにある画像は操作説明用のスクリーンショットです。
