## ゲーム連携の追加許諾

GPLv3 第7条に基づき、活俠傳とゲーム同梱の実行時ライブラリへのリンク・連携、およびその連携を行う本プロジェクトの配布を許可する。対象は追加許諾文で特定する。ゲーム側のソース提供を求めず、本プロジェクトのコードと改変・ビルド手順には引き続き GPL を適用する。

この許諾はゲーム本体や素材の転載・再配布を許可するものではない。本プロジェクトのライセンスで第三者の権利を上書きしない。参考にした本編処理と素材の由来は監査レポートに記録している。

## バイナリを再配布するとき

- GPL 本文、著作権表示、追加許諾、必要な第三者表記を保持する。
- 配布する DLL / EXE に対応するソースコードとビルド手順を、GPL の条件に従って提供する。配布スクリプトは `BepInEx/plugins/LoMScenarioAddon/Source/LoMScenarioKit-source.zip` にそのビルドで使用したプロジェクトのソースを同梱する。
- 制作ツールの `pack` も、導入先のソース ZIP とライセンス一式を引き継ぐ。DLL を改造して差し替えた場合は、それに対応するソース ZIP も更新する。ツールは両者の対応を自動証明しない。
- 変更したコードには変更の事実と日付を明示し、配布する対象コードに GPLv3 を適用する。自分の改変部分にゲーム連携の追加許諾を引き継ぐかは、追加許諾本文に従う。

ソース ZIP にはビルド成果物、ゲーム DLL、他 MOD の配布物、旧 Git 履歴を含めない。開発環境・依存パッケージとビルド方法は [開発メモ](development.md) を参照。
