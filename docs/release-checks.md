# 配布確認

[README に戻る](../README.md) · [開発メモ](development.md)

## 公開前の確認手順

1. `LICENSE`、ゲーム連携の追加許諾、`licenses/` とサンプルの表示を確認する。適用範囲は [ライセンスと再配布](licensing.md) を参照。
2. `python3 -m unittest discover -s tests -v` で配布処理の失敗時の停止・既存ファイルの退避を確認する。
3. `LOM_GAME_DIR` を指定して配布スクリプトを実行する。ビルド・サンプル検査が成功したことを確認する。
4. ZIP を別フォルダへ展開し、DLL・シナリオ・説明書・ライセンスが揃い、ゲーム DLL や他 MOD が混入していないことを確認する。
5. Windows のゲーム環境で下の実機確認を行い、ゲームの版・BepInEx の版・結果を記録する。
6. 公開する Git 履歴にゲーム内部資料や認証情報が含まれないことを確認する。

## 実機で確認する項目

- [ ] 配布 ZIP を新規導入し、パッチャーとプラグインの読み込みをログで確認する。
- [ ] 専用の`Addon.log`/`Patcher.log`に記録され、通常時に同じメッセージが共通ログへ重複しない。Play/Debug切り替え、設定した間隔、エラー・正常終了時の保存も確認する。
- [ ] 裏山で登場シナリオを開始し、キャラ・画像・音声が表示／再生される。
- [ ] Addressables 経由のイベント画像で、通常・全画面・アイテム表示、公式画像との切り替え、繰り返し表示、シーン遷移を確認する（[確認項目](story-pictures-investigation.md)）。
- [ ] 好感度・フラグを含むセーブとロードが成功する。
- [ ] 制作ツールの Windows 版 exe でサンプルを検査できる。
- [ ] 旧版から更新し、設定を保ったまま読み込める。自作シナリオの退避・復元も確認する。
- [ ] アドオンを削除し、追加決闘中ではないセーブを読み込める。
- [ ] 日本語化 MOD なしの環境で、起動・言語選択・サンプルの読み込みを確認する。

ゲームの確認対象は README の環境情報を参照。まだ確認していない組み合わせを動作確認済みとしない。
