# ADR 002: 短い起動コマンドに環境設定をまとめる

## 背景

GUI起動にはCargoの長い引数が必要だった。WSLgではEGL/Zink初期化に失敗し、描画設定も毎回指定する必要があった。

## 決定

ルートの `./editor` をLinux・macOS・WSLの起動窓口にする。WSLの環境変数がある場合はX11を選び、描画ドライバーの指定がなければCPU描画を使う。引数と呼び出し元の作業ディレクトリは保持する。

## 理由

現在のWSLgで起動を確認した設定をスクリプトへ移せば、環境変数やCargoの引数を覚えずに使える。Cargo経由の起動を維持し、コード更新後に古いバイナリを実行することも避ける。

## 影響

従来のCargoコマンドも利用でき、WSL以外の描画設定は変更しない。通常起動では内部のバックエンド名を表示せず、macOS専用のメニュー初期化関数はmacOSでのみコンパイルする。README、起動ガイド、ソースZIPに起動スクリプトを反映する。
