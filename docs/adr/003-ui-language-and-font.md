# ADR 003: 表示言語とフォントをエディター内で揃える

## 背景

OSのフォント候補を順に探す方式では、WSLでWenQuanYiが選ばれ、日本語の字形や読みやすさが環境によって変わっていた。イベント設定や添削画面には翻訳を通らない文言も残っていた。WSLgのXcursorは画面の高さから45pxを選び、入力欄上のI字ポインターが大きく表示されていた。

## 決定

Noto Sans CJK Regular 2.004の未改変コレクションを同梱し、表示言語に合うJP・KR・SC・TCの字形を選ぶ。本文は14pxを基準とし、設定で言語を変えるとフォントも更新する。出典、ハッシュ、OFLをフォントと一緒に保存する。

既存の日本語・簡体字・繁体字・韓国語に英語を追加する。既存辞書とネイティブUI辞書を引き継ぎ、追加画面と動的な通知は`ui-translations.json`にまとめる。値を含む文は翻訳後に名前付きプレースホルダーへ値を一度だけ挿入する。作品本文、作者が付けた名前、IDや参照は翻訳しない。英語のゲーム用語辞書にない固有名は既存の原表記へ戻す。

UIの5言語と、実行環境が受け付けるシナリオ翻訳の4言語は別に扱う。翻訳したエラー文を成功・失敗の判定に使わず、Luaの書き出し可否はコンパイル結果として保持する。

WSL用ランチャーは`XCURSOR_SIZE`が未指定の場合に24を設定する。指定済みの値は保持し、OS全体の設定は変更しない。

## 理由と影響

同梱によって初回起動から5言語を表示でき、OSごとの追加フォント設定が不要になる。フォント分だけソースとバイナリが約19.5MB増えるが、単一コレクションで各言語の輪郭データを共有する。ソースZIPにもフォントとライセンスを含め、そこから再ビルドできるようにする。

検証は辞書・プレースホルダー・選択肢の翻訳、フォントの描画、設定変更後の作品データ保持、コンパイル失敗時の書き出し防止、配布ソースの同梱物を対象とする。WSLでは実際のウィンドウとマウスポインターも確認する。
