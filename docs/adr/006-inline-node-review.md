# ADR 006: ノード編集欄に判定とコメントを置く

## 背景

ノードの添削には専用ページへの移動と対象の切り替えが必要だった。判定もドロップダウン式で、本文やフロー図を見ながら繰り返し使うにはクリックが多かった。

## 決定

ノード編集欄の下に、高さを変えられる判定・コメント欄を常設する。判定はボタンで直接選ぶ。フロー図と一覧のどちらから選んでも、選択中のノードを対象にする。

描画と投稿処理は既存の添削ページと共用する。入力中の本文・返信先は章IDとノードIDごとに保持し、対象を切り替えても移動先へ引き継がない。ほかの対象の下書きには移動・破棄の操作を用意する。

## 理由

ノードの設定をスクロールしても添削操作を使え、専用ページへの往復を減らせる。処理と下書きを共用することで、同じ対象をどちらの画面から開いても添削を続けられる。

## 影響

章全体の添削、資料、保存履歴は既存のページを使う。添削データの形式、GUIとCLIの共有、保存操作は変更しない。下書きの保持はセッション中のみで、保存前に投稿か破棄が必要。判定・投稿・返信・解決状態・対象の切り替え・保存後の再読み込みと、フロー図からの実操作をテストする。
