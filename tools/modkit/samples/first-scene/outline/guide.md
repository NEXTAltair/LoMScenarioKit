# 「裏山でひと休み」の使い方

画像付きの手順は「ヘルプ」（F1）の「1. サンプルを開く」から順に読めます。

はじめてエディターを使う人向けのサンプルです。趙活と大師兄の会話を再生し、台詞や表情を変えてみましょう。

1. 「ファイル → サンプルから始める」で編集用コピーを開きます。
2. 右下の「再生」で始め、台詞を読んだら画面をクリックして進めます。
3. 変えた内容は「ファイル → 全章を保存」で保存します。

初回は「再生する」まで読めば試せます。編集するときは「変えてみる」、表示や音に困ったら「困ったとき」を参照してください。

## 素材を準備する

立ち絵・背景をまだ抽出していない場合だけ行います。

1. 「ファイル → ゲームからプレビュー素材を抽出…」を選びます。
2. `Mortal_Data`が入っているゲームフォルダーを指定します。
3. 抽出が終わるまで待ちます（次回からは抽出済みの画像を使います）。

BGMの再生にはFFplayが必要です。曲は再生時に必要な分だけ準備されます。設定済みのゲームフォルダーと画像キャッシュは、このサンプルでも使えます。

## 再生する

1. 「ファイル → サンプルから始める」を選びます。
2. 右側が「画面プレビュー」になっていることを確認します。
3. 右下の「再生」を押します。裏山の背景、BGM、2人の立ち絵が表示され、最初の台詞で待ちます。
4. 台詞を読んだら、画面プレビューをクリックして次へ進めます。「次へ」ボタンでも進められます。
5. 「少し休む」「一緒に稽古する」が出たら、画面プレビュー内で片方をクリックします。
6. 選んだ先の台詞を確認し、画面をクリックして続きを進めます。
7. もう一方も試すには、左の「08 選択肢分岐」を選び、別の選択肢をクリックします。

台詞と選択肢では入力を待ちます。待っている間もBGMは流れます。背景や人物の登場などの演出は自動で進み、「停止」を押すと演出とBGMが止まります。続けるときは「再生」を押してください。

## 変えてみる

左の一覧で編集したい行を選ぶと、中央に設定が出ます。ノードは、台詞や人物の登場といった一つの処理を表します。

| やってみること | 選ぶ行 | 中央で変える場所 |
|---|---|---|
| 台詞を自分の言葉にする | 05 台詞「趙活、こんな所にいたのか。」 | 「テキスト」 |
| 同じ人物の表情を変える | 05 台詞 | 「表情」 |
| 立ち位置を変える | 03 人物登場、または04 人物登場 | 「立ち位置」 |
| 曲を変える | 02 音楽 | 曲の選択欄 |
| 選択肢の言葉を変える | 08 選択肢分岐 | 各項目のテキスト |

表情や位置の変更は右側の画面で確かめられます。曲を変えたら、音楽の行か、その後の台詞を選んで「再生」を押してください。「フロー図」では2つの選択肢が別の会話を通り、最後に合流する様子を確認できます。

最初は選択肢の移動先を保ったまま、台詞と選択肢の言葉を変えてみてください。

## 保存する

1. 「ファイル → 全章を保存」を選びます（Windows・Linuxは`Ctrl+S`、macOSは`⌘S`）。
2. 続きを編集するときは「ファイル → 最近使ったファイル」から、このサンプルのコピーを開きます。

メニューから開くたびに、新しい編集用コピーを作ります。保存場所はOSごとの`LoMScenarioKit/projects/first-scene-…/`です。コピーには制作データ、この説明、ライセンスが含まれます。

| OS | 作業フォルダーの場所 |
|---|---|
| Linux・WSL | `~/.local/share/LoMScenarioKit/projects/` |
| Windows | `%APPDATA%/LoMScenarioKit/projects/` |
| macOS | `~/Library/Application Support/LoMScenarioKit/projects/` |

このサンプルはLoMScenarioAddon用です。「Addonを書き出す」でLuaと設定を書き出せます。ゲーム内に導入して試す操作は、エディターのプレビューとは別です。

## 用語

| 用語 | 意味 |
|---|---|
| ノード | 左の一覧にある、台詞・人物登場・選択肢などの一つの処理 |
| BGM | 会話の間に流れる背景音楽 |
| プレビュー | エディター内で表示や進行を確認する画面 |

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 立ち絵の代わりに人型の枠が出る | 「素材を準備する」の手順で画像を抽出します |
| 音が出ない | ゲームフォルダーとFFplayを確認し、「再生」を押します。ノードの選択だけでは音は鳴りません |
| 曲の準備中に止まる | 「音楽を準備しています…」が消えるまで待ちます |
| 選択肢で止まった | 画面内の選択肢をクリックします。選んだ先から会話を続けられます |
| 台詞から先に進まない | 画面プレビューをクリックするか、右下の「次へ」を押します |

解決しない場合は、選んだ行と表示されたエラーを添えて [GitHub Issues](https://github.com/NEXTAltair/LoMScenarioKit/issues) に報告してください。
