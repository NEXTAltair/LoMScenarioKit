1. サンプルを開く

サンプルの最初の台詞を「Hello!」に変え、再生してから保存するまでを、順番に試します。まずエディターを起動してください。

画像は日本語UIです。画像をクリックすると拡大できます。黒い帯は個人のパスやフォルダー名を隠しています。

1-1. 「ファイル → サンプルから始める」を選ぶ

上部の「ファイル」を開き、上から2番目の「サンプルから始める」を押します。

1-2. 「裏山でひと休み」が開いたことを確認する

左に01～17のステップが並びます。素材をまだ準備していない場合、右の背景は黒いままで正常です。元のサンプルとは別の編集用コピーが作られます。

次へ：2. 画像を準備する

2. 画像を準備する

2-1. 抽出メニューを開く

「ファイル → ゲームからプレビュー素材を抽出…」を選びます。すでに背景や立ち絵が表示される場合は、手順3へ進んでください。

2-2. Mortal_Dataがあるフォルダーを選ぶ

「フォルダーのパス」にゲームのインストール先を入力して「移動」を押します。一覧に「Mortal_Data」があることを確認し、「このフォルダーを使う」を押します。黒い帯の部分は自分の環境のパスになります。

2-3. 抽出の完了を待つ

進捗が表示されます。「閉じて編集を続ける」でこの画面を閉じても処理は続きます。完了すると結果が表示され、画像が自動で読み込まれます。

2-4. 背景が表示されたことを確認する

結果を閉じて左の「01 公式背景切替」を選びます。右が黒い画面から裏山の背景に変われば準備完了です。

前へ：1. サンプルを開く · 次へ：3. 台詞を書き換える

補足：素材を変更する

主要人物は「人物 → 外観 → 表情」の順に選びます。外観ごとに使用可能な表情のみ表示します。外観変更後に使えない表情は通常表情に戻ります。別の公式人物設定へ切り替える場合は、古い外観を退場させてから新しい外観を登場させます。

ゲームのプレビュー素材はこの端末に保存します。自作素材はユーザーコンテンツから作品に追加します。

既存の素材庫はファイルメニューから選択。プレビュー画像は作品に自動では含まれません。

自作素材を取り込む

素材管理の作品の素材から素材インポートで追加し、ステップのフォームで選びます。見えないときは素材庫と人物・表情を確認して先頭から再生してください。

3. 台詞を書き換える

3-1. 左の「05 台詞」を選ぶ

中央の「テキスト」に「趙活、こんな所にいたのか。」が表示されます。左の一覧がスクロールしている場合は、05番まで戻してください。

3-2. 本文を「Hello!」に置き換える

中央の「テキスト」欄をクリックし、全文を選択して「Hello!」と入力します。右の会話文も「Hello!」になれば変更できています。

前へ：2. 画像を準備する · 次へ：4. 再生して台詞を進める

ノードに判定・コメントを付ける

左の一覧かF7のフロー図でノードを選ぶと、中央下に「判定・コメント」が表示されます。「良い」「要修正」などを1回押して判定し、指摘は入力して「コメントを追加」を押します。既存のコメントには返信と解決状態のボタンがあります。境界をドラッグすると欄の高さを変えられます。

入力途中で別ノードへ移っても下書きは元の対象に残ります。「入力中のコメント」から戻るか破棄してください。投稿後はCtrl+S（macOSは⌘S）で保存します。章全体の添削は「資料・添削・履歴」を使います。

4. 再生して台詞を進める

4-1. 右下の「先頭」を押す

再生位置が「1 / 17」に戻ります。この操作で編集した台詞は消えません。

4-2. 「再生」を押す

背景と人物の登場が進み、05番の「Hello!」で止まります。BGMにはFFplayが必要です。初回は曲の準備が終わるまで待ってください。

4-3. 右の画面プレビューを1回クリックする

06番の「少し風に当たりたくて。」に進みます。台詞は時間では進まず、クリックを待ちます。右下の「次へ」でも進められます。

前へ：3. 台詞を書き換える · 次へ：5. 選択肢を試す

補足：ゲームで試遊する

Windows の試遊または F5 は検査後に独立した一時パッケージを作りゲームを起動します。ゲームの設定と MOD 一覧は上部の「ゲームと MOD」にあります。Mac はゲーム試遊非対応です。

転換時間は目安です。音声、フィルター、戦闘などの実際の効果はゲーム内で確認してください。

5. 選択肢を試す

5-1. 選択肢まで進み、「一緒に稽古する」を押す

06番から画面を2回クリックすると、08番の選択肢が出ます。画面内の下のボタン「一緒に稽古する」を選びます。

5-2. 選んだ先の台詞を確認する

11番の「大師兄、お手柔らかに。」が表示されます。別の分岐を試すときは、左の「08 選択肢分岐」を選び、「少し休む」を押します。

前へ：4. 再生して台詞を進める · 次へ：6. 保存して開き直す

補足：選択肢・ジャンプ・終了を設定する

ジャンプがなければ左側の順序で再生します。選択肢や条件分岐で行き先を変えられます。

  1. 選択後に表示する会話を先に用意。
  2. 選択肢分岐を追加し、文章と行き先を設定。
  3. F7 で経路を確認してから各ルートを再生。

シナリオ終了の設定

  • 次の章が空欄：章を終えて自由モードへ戻る。
  • 次の章を指定：終了後にその章を再生する。
独立した話：会話 → 終了（次の章は空欄）
続きのある話：会話 → 終了（次の章を選択）
フラグは「人物に会った」などの記録。条件分岐でその記録を確認できます。

6. 保存して開き直す

6-1. 「ファイル → 全章を保存」を押す

編集したコピーへ保存します。Windows・LinuxはCtrl+S、macOSは⌘Sでも保存できます。

6-2. 画面左下の「保存済み」を確認する

この表示になれば保存できています。保存するまで、変更は開いているエディター内だけにあります。

6-3. 「最近使ったファイル」から同じコピーを開く

「ファイル → 最近使ったファイル」を開き、いま保存したfirst-scene-…を選びます。「サンプルから始める」を選ぶと別のコピーができるので、続きを編集するときは最近使ったファイルを使います。

6-4. 05番を選び、「Hello!」が残っていることを確認する

中央のテキストと右の会話文を確認できれば、編集・再生・保存・開き直しを一通り完了です。次は好きな台詞に変えてみてください。F6で現在の章を検査できます。

前へ：5. 選択肢を試す

人物の登場と会話

登場は立ち絵を配置し、会話は台詞を表示します。登場してから移動や退場を設定します。

背景変更 → 人物登場 → 会話 → 人物退場 → 終了
  1. ステップ追加の演出から背景と人物を加えます。
  2. 人物、表情、位置を選択。すぐに配置する場合はフェードと移動時間を両方 0 にします。
  3. 会話で同じ人物を選び、台詞を入力。情景描写にはナレーションを使います。
立ち絵が見えない場合は素材庫を読み込んでください。素材の項目で手順を確認できます。

複数の動作を同時に実行

通常のステップは順番に進みます。同時実行グループはすべて一緒に始まり、全動作が終わってから次へ進みます。

例：二人が同時に退場

  1. 二人を登場させ、同時実行グループを追加。
  2. 人物退場を二つ加え、別々の人物を選択。
  3. 両方を 0.5 秒に設定。続く会話はグループの外に置きます。
同時実行グループ
  人物 A 退場：0.5 秒
  人物 B 退場：0.5 秒
↓ 全動作が完了
次の会話
一組 2～32 動作。同一人物や画面チャンネルは重複操作できません。会話、選択肢、戦闘、ジャンプは外に配置。音楽・効果音・ループ効果は開始時に完了扱いのため、必要なら待機を加えます。

場面を開く前に人物を配置

暗幕を掛け、その裏で背景と人物を準備し、最後に暗幕を開きます。

  1. トランジションのインで暗幕を掛ける。
  2. 背景を変更する。
  3. 人物を登場させ、フェードと移動時間を 0 にする。複数なら同時実行グループを使う。
  4. トランジションのアウトで暗幕を開く。
暗幕を掛ける → 背景変更・人物配置 → 暗幕を開く → 会話
イン／アウトは暗幕の出現／消失です。エディターの時間は確認用の目安で、実際の時間はゲーム側で決まります。

検査結果の読み方

結果ウィンドウの結論を先に読み、問題の場所へ戻って修正します。元のデータは技術詳細にあります。

  • 正常：今回の検査では問題なし。
  • 修正が必要：表示された項目を修正。
  • ゲーム内確認待ち：オフラインでは判断できず、まだ合格ではない。

F6 は現在の章。全体の検査は公開ページの公開検査・梱包から行います。

長い処理は畳んで編集を続けられます。下部から進捗や結果を再表示でき、完了時にも通知します。

用語をやさしく説明

フォームでの制作にプログラミング知識は不要です。

  • ノード：物語の一つのステップ。
  • フラグ：出来事が起きたかを記録。
  • 条件分岐：記録や数値で行き先を選ぶ。
  • 素材庫：この端末で表示する画像集。
  • 作品パッケージ：書き出した .lommod ファイル。
  • ホスト：ゲームに作品を読み込ませる接続部品。
  • API：プログラムから使う機能の入口。
  • Lua：エディターが手順から生成するコード。通常は手書き不要。

保存、言語、ショートカット

Mac はアプリメニューの設定か ⌘,、Windows/Linux は設定か Ctrl+, で表示言語を変更します。物語の翻訳は編集メニューの多言語から行います。

  • ⌘S / Ctrl+S：保存。
  • F1：ヘルプ。
  • F6：現在の章を検査。
  • F7：フローチャート。
  • F5：Windows ゲーム試遊。
  • Esc：ヘルプやダイアログを閉じる。
