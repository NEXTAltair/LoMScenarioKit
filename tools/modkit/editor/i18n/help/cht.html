1. 開啟範例

先把範例的第一句對白改成「Hello!」，再播放、儲存並重新開啟。請先啟動編輯器，然後依序操作。

截圖使用日語介面，點擊圖片可放大。黑色遮罩用於隱藏個人路徑和資料夾名稱。

1-1. 在「檔案」中選擇「從範例開始」

開啟頂部的「檔案」選單，選擇第二項「從範例開始」。

1-2. 確認範例已開啟

左側列出01～17步。尚未準備素材時，右側背景為黑色是正常的。編輯器已建立獨立的範例副本。

下一步：2. 準備預覽圖片

2. 準備預覽圖片

2-1. 開啟擷取選單

選擇「檔案 → 從遊戲提取預覽素材…」。若已能看到背景和人物，可直接進入第3節。

2-2. 選擇包含Mortal_Data的資料夾

在資料夾路徑中輸入遊戲安裝位置，點擊「前往資料夾」。確認清單中有Mortal_Data，再點擊「使用此資料夾」。黑色遮罩處應是自己的路徑。

2-3. 等待擷取完成

畫面顯示進度。關閉視窗繼續編輯不會中斷擷取。完成後會顯示結果，並自動載入圖片。

2-4. 確認背景出現

關閉結果，選擇左側第01步。右側從黑色畫面變成後山背景，就準備好了。

上一步：1. 開啟範例 · 下一步：3. 修改一句對白

補充：修改素材

重要人物依「人物 → 外觀 → 表情」選擇，例如「虞小梅 → 入魔」。只列出該外觀可用的表情；切換外觀時，不可用的舊表情會恢復為正常表情。場中換用另一官方人物設定時，先讓舊外觀退場，再讓新外觀登場。

遊戲預覽素材留在本機供編輯器顯示；自製素材由使用者內容加入作品。

已有素材庫可從檔案選單載入。遊戲預覽圖片不會自動加入匯出的作品。

匯入自製素材

素材管理 → 作品素材 → 匯入素材，再到步驟表單選取。圖片沒出現時，確認素材庫、人物及表情後，從開頭重播。

3. 修改一句對白

3-1. 選取左側第05步對白

中央的文字欄顯示「趙活、こんな所にいたのか。」。若清單已捲動，請找到05。

3-2. 把文字改成「Hello!」

點擊中央文字欄，全選原文並輸入Hello!。右側對白也變成Hello!，表示修改已生效。

上一步：2. 準備預覽圖片 · 下一步：4. 播放並推進對白

評定節點並新增評論

在左側清單或F7流程圖中選擇節點，編輯區下方會顯示「評定與評論」。按一下按鈕即可評定，輸入後按「新增評論」即可留下意見。已有評論可以回覆、標記為已解決或重新開啟。拖曳上緣可調整區域高度。

切換節點時，未提交的評論保留在原來的節點。「輸入中的評論」可返回或捨棄草稿。請先提交或捨棄草稿，再按Ctrl+S（macOS為⌘S）儲存。章節整體的審閱仍在「資料與審閱」中。

4. 播放並推進對白

4-1. 點擊預覽下方的「開頭」

播放位置回到1 / 17，已修改的對白會保留。

4-2. 點擊「播放」

背景與人物依序出現，接著在第05步的Hello!處等待。BGM需要FFplay；首次使用時請等曲目準備完成。

4-3. 點擊一次畫面預覽

進入第06步「少し風に当たりたくて。」。對白會等待點擊，不會計時跳過；也可點擊下方的「下一步」。

上一步：3. 修改一句對白 · 下一步：5. 試選一個選項

補充：在遊戲中試玩

Windows 的試玩或 F5 會檢查作品、產生獨立臨時包並啟動遊戲。遊戲目錄、自動設定與 MOD 清單在頂欄「遊戲與 MOD」頁面管理；Mac 不提供遊戲試玩。

轉場時間為示意；音訊、濾鏡、戰鬥及其他遊戲系統仍需在遊戲確認。

5. 試選一個選項

5-1. 推進到選項，選擇「一緒に稽古する」

從第06步再點擊畫面兩次，就會看到第08步的選項。點擊下方的「一緒に稽古する」（一起練功）。

5-2. 確認分支對白

第11步顯示「大師兄、お手柔らかに。」。要試另一條路，選取左側第08步，再點擊「少し休む」（休息一下）。

上一步：4. 播放並推進對白 · 下一步：6. 儲存並重新開啟

補充：設定選項、跳轉與結束

未指定跳轉時按左側順序播放。選項或條件分支可指定不同後續步驟。

  1. 先準備選項後要播放的對白。
  2. 加入選項分支，填文字並為每項選擇後續步驟。
  3. 按 F7 看流程圖，再逐條預覽。

結束劇情怎麼填

  • 下一章節留空：結束目前章節，回自由模式。
  • 選擇下一章節：結束後接著播放該章。
獨立故事：對白 → 結束劇情（下一章節留空）
接續故事：對白 → 結束劇情（選下一章節）
旗標是事件記錄，例如已見過師兄。條件分支可依這個記錄決定下一段。

6. 儲存並重新開啟

6-1. 選擇「檔案 → 儲存全部章節」

修改會儲存到這個副本。Windows/Linux也可用Ctrl+S，macOS用⌘S。

6-2. 確認左下角顯示「已儲存」

出現這個狀態就表示已寫入磁碟。儲存前，修改只存在於目前開啟的編輯器中。

6-3. 從最近開啟重新開啟同一個副本

選擇「檔案 → 最近開啟」，再選剛儲存的first-scene-…。再次選擇「從範例開始」會建立另一個副本，繼續編輯時請用最近開啟。

6-4. 選取第05步，確認Hello!還在

檢查中央文字和右側對白。這樣就完成了修改、播放、儲存和重新開啟。接著可換成自己的台詞。F6可檢查目前章節。

上一步：5. 試選一個選項

人物登場與對白

人物登場負責放入立繪，對白負責顯示台詞。先登場，再移動或退場。

切換背景 → 人物登場 → 對白 → 人物退場 → 結束劇情
  1. 從「＋ 新增步驟」的演出分類加入背景與人物。
  2. 選擇人物、表情、站位。直接就位時，淡入與移動時間都設為 0。
  3. 加入對白，選同一人物並填台詞；環境描述可用旁白。
沒有立繪時，先確認已載入預覽素材。詳見「讓預覽顯示素材」。

讓多個動作同時發生

一般步驟依序執行；同時執行群組內的動作一起開始，全部完成後才繼續下一步。

例子：兩人一起退場

  1. 先讓兩人登場，再加入同時執行群組。
  2. 新增兩個人物退場動作，各選不同人物。
  3. 兩個時間都填 0.5 秒，後續對白放在群組外。
同時執行群組
  人物甲退場：0.5 秒
  人物乙退場：0.5 秒
↓ 全部結束
後續對白
每組 2～32 個演出動作，不能重複控制同一人物或畫面通道。對白、選項、戰鬥與跳轉放在組外。音樂、音效和循環特效啟動後即視為完成，可加等待控制停留。

換景後人物已經就位

先用黑幕蓋住畫面，在幕後換景並安排人物，最後揭幕。

  1. 轉場選淡入，蓋上黑幕。
  2. 切換到新背景。
  3. 安排人物登場，淡入與移動時間都設 0；多人可放進同時執行群組。
  4. 轉場選淡出，揭開黑幕。
淡入蓋幕 → 換背景、人物就位 → 淡出揭幕 → 對白
這裡的淡入與淡出指黑幕的出現和消失。編輯器轉場節奏為示意，實際時間由遊戲決定。

看懂檢查與操作結果

先看結果視窗頂部結論，再依問題位置修改。原始資料收在技術詳情。

  • 狀態正常：此次檢查未發現問題。
  • 需要修正：依提示補填或修正劇情。
  • 待遊戲確認：離線不能確認，尚未通過。

F6 檢查目前章節。完整檢查：發佈 → 發布檢查與打包 → 發布檢查。

耗時任務可收起繼續編輯，從底部重新開啟進度或結果；完成後會提示。

常用詞，簡單說

使用表單創作不需要先學程式。

  • 節點：劇情的一步。
  • 旗標：記住某件事是否發生。
  • 條件分支：依記錄或數值決定去向。
  • 預覽素材庫：本機顯示立繪與背景的圖片集合。
  • 作品包：匯出的 .lommod 檔案。
  • 宿主：讓遊戲載入作品的接入元件。
  • API：寫程式時使用的功能介面。
  • Lua：編輯器依步驟產生的程式，通常不需手寫。

儲存、語言與快捷鍵

Mac 從應用程式選單的設定或 ⌘, 開啟設定；Windows/Linux 使用設定或 Ctrl+,。作品台詞翻譯在編輯選單的多語言。

  • ⌘S / Ctrl+S：儲存。
  • F1：幫助。
  • F6：檢查目前章節。
  • F7：流程圖。
  • F5：Windows 遊戲試玩。
  • Esc：關閉幫助或提示視窗。
