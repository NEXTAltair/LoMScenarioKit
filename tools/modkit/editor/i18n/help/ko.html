1. 샘플 열기

샘플의 첫 대사를 “Hello!”로 바꾸고 재생한 뒤, 저장하고 다시 열어 봅니다. 먼저 편집기를 실행하세요.

이미지는 일본어 UI입니다. 이미지를 클릭하면 확대됩니다. 검은 막대는 개인 경로와 폴더 이름을 가립니다.

1-1. 파일 → 예제로 시작 선택

상단의 파일 메뉴를 열고 두 번째 항목인 예제로 시작을 누릅니다.

1-2. 샘플이 열렸는지 확인

왼쪽에 01~17 단계가 표시됩니다. 이미지를 준비하기 전에는 오른쪽 배경이 검은색이어도 정상입니다. 원본과 별도의 편집용 복사본이 만들어집니다.

다음: 2. 미리보기 이미지 준비

2. 미리보기 이미지 준비

2-1. 추출 메뉴 열기

파일 → 게임 미리보기 소재 추출…을 선택합니다. 배경과 인물이 이미 보이면 3단계로 넘어가세요.

2-2. Mortal_Data가 있는 폴더 선택

폴더 경로에 게임 설치 위치를 입력하고 이동을 누릅니다. 목록에 Mortal_Data가 있는지 확인한 뒤 이 폴더 사용을 누릅니다. 검은 막대 위치에는 자신의 경로가 표시됩니다.

2-3. 추출 완료 기다리기

진행 상황이 표시됩니다. 창을 닫고 편집을 계속해도 추출은 진행됩니다. 완료되면 결과가 표시되고 이미지가 자동으로 불러와집니다.

2-4. 배경 표시 확인

결과를 닫고 왼쪽 01 단계를 선택합니다. 검은 화면 대신 뒷산 배경이 보이면 준비가 끝났습니다.

이전: 1. 샘플 열기 · 다음: 3. 대사 바꾸기

추가: 소재 변경

주요 인물은 인물 → 외형 → 표정 순서로 선택합니다. 해당 외형에서 사용 가능한 표정만 표시합니다. 외형을 바꾼 뒤 사용할 수 없는 표정은 기본 표정으로 돌아갑니다. 다른 공식 인물 설정으로 바꿀 때는 이전 외형을 퇴장시킨 뒤 새 외형을 등장시키세요.

게임 미리보기 그림은 이 컴퓨터에 저장합니다. 직접 만든 소재는 사용자 콘텐츠에서 작품에 추가합니다.

기존 소재는 파일 메뉴에서 불러옵니다. 미리보기 그림은 작품에 자동으로 포함되지 않습니다.

자작 소재 가져오기

소재 관리의 작품 소재에서 가져온 뒤 단계 양식에서 선택합니다. 그림이 없다면 소재 보관함, 인물, 표정을 확인하고 처음부터 재생하세요.

3. 대사 바꾸기

3-1. 왼쪽 05 대사 선택

가운데 텍스트 칸에 “趙活、こんな所にいたのか。”가 표시됩니다. 목록을 스크롤했다면 05를 찾으세요.

3-2. 텍스트를 “Hello!”로 바꾸기

가운데 텍스트 칸을 클릭하고 전체 내용을 선택한 뒤 Hello!를 입력합니다. 오른쪽 대사도 Hello!로 바뀌면 적용된 것입니다.

이전: 2. 미리보기 이미지 준비 · 다음: 4. 재생하고 다음 대사로 이동

4. 재생하고 다음 대사로 이동

4-1. 미리보기 아래 처음 버튼 누르기

재생 위치가 1 / 17로 돌아갑니다. 편집한 대사는 유지됩니다.

4-2. 재생 누르기

배경과 인물이 등장하고 05 단계의 Hello!에서 기다립니다. BGM에는 FFplay가 필요하며, 처음에는 곡 준비가 끝날 때까지 기다리세요.

4-3. 화면 미리보기 한 번 클릭

06 단계의 “少し風に当たりたくて。”로 넘어갑니다. 대사는 시간이 지나도 넘어가지 않고 클릭을 기다립니다. 아래 다음 버튼으로도 진행할 수 있습니다.

이전: 3. 대사 바꾸기 · 다음: 5. 선택지 확인

추가: 게임에서 시험 플레이

Windows의 시험 플레이나 F5는 검사 후 임시 독립 패키지를 만들고 게임을 실행합니다. 게임 설정과 MOD 목록은 상단 게임 및 MOD에 있습니다. Mac은 게임 시험을 지원하지 않습니다.

전환 시간은 예시입니다. 소리, 필터, 전투 등 실제 효과는 게임에서 확인해야 합니다.

5. 선택지 확인

5-1. 선택지까지 진행한 뒤 아래 선택지 누르기

06 단계에서 화면을 두 번 클릭하면 08 단계의 선택지가 나타납니다. 아래의 “一緒に稽古する”(함께 수련하기)를 누릅니다.

5-2. 선택한 분기의 대사 확인

11 단계의 “大師兄、お手柔らかに。”가 표시됩니다. 다른 분기는 왼쪽 08 단계를 선택한 뒤 “少し休む”(잠깐 쉬기)를 눌러 확인합니다.

이전: 4. 재생하고 다음 대사로 이동 · 다음: 6. 저장하고 다시 열기

추가: 선택지, 이동, 종료 설정

분기 설정이 없으면 왼쪽 순서대로 재생합니다. 선택지와 조건 분기로 다음 위치를 정할 수 있습니다.

  1. 선택 뒤에 나올 대사를 먼저 만듭니다.
  2. 선택지 분기를 추가하고 글과 다음 단계를 지정합니다.
  3. F7으로 경로를 확인하고 하나씩 재생합니다.

스토리 종료 설정

  • 다음 장을 비우면 현재 장이 끝나고 자유 모드로 돌아갑니다.
  • 다음 장을 선택하면 끝난 뒤 그 장을 재생합니다.
독립 스토리: 대사 → 종료(다음 장 비움)
이어지는 스토리: 대사 → 종료(다음 장 선택)
표식은 누군가를 만났다는 사건 기록입니다. 조건 분기가 이 기록을 확인해 경로를 고릅니다.

6. 저장하고 다시 열기

6-1. 파일 → 모든 장 저장 선택

편집한 복사본에 저장됩니다. Windows/Linux는 Ctrl+S, macOS는 ⌘S도 사용할 수 있습니다.

6-2. 왼쪽 아래 저장됨 확인

이 상태가 표시되면 디스크에 저장된 것입니다. 저장 전 변경 사항은 열려 있는 편집기에만 있습니다.

6-3. 최근 파일에서 같은 복사본 다시 열기

파일 → 최근 파일에서 방금 저장한 first-scene-…를 선택합니다. 예제로 시작을 다시 누르면 새 복사본이 생기므로 이어서 편집할 때는 최근 파일을 사용하세요.

6-4. 05 단계를 선택해 Hello! 확인

가운데 텍스트와 오른쪽 대사를 확인합니다. 편집, 재생, 저장, 다시 열기를 모두 마쳤습니다. 다음에는 원하는 대사로 바꿔 보세요. F6으로 현재 장을 검사할 수 있습니다.

이전: 5. 선택지 확인

인물 등장과 대사

등장은 인물 그림을 배치하고 대사는 글을 보여 줍니다. 먼저 등장시킨 뒤 이동이나 퇴장을 설정합니다.

배경 변경 → 인물 등장 → 대사 → 인물 퇴장 → 종료
  1. 단계 추가의 연출 분류에서 배경과 인물을 넣습니다.
  2. 인물, 표정, 위치를 선택합니다. 즉시 배치하려면 페이드와 이동 시간을 모두 0으로 설정합니다.
  3. 대사에서 같은 인물을 선택하고 글을 씁니다. 환경 묘사는 내레이션을 씁니다.
인물 그림이 없다면 미리보기 소재를 불러왔는지 확인하세요. 소재 항목에 절차가 있습니다.

여러 동작을 동시에 실행

보통 단계는 차례대로 실행됩니다. 동시 실행 그룹은 함께 시작하고 모두 끝난 뒤 다음으로 진행합니다.

예제: 두 인물 동시 퇴장

  1. 두 인물을 등장시키고 동시 실행 그룹을 넣습니다.
  2. 퇴장 동작을 두 개 추가하고 서로 다른 인물을 선택합니다.
  3. 시간을 각각 0.5초로 설정합니다. 다음 대사는 그룹 밖에 둡니다.
동시 실행 그룹
  인물 A 퇴장: 0.5초
  인물 B 퇴장: 0.5초
↓ 모두 끝남
다음 대사
한 그룹은 2~32개 동작입니다. 같은 인물이나 화면 채널을 중복 제어할 수 없습니다. 대사, 선택지, 전투, 이동 분기는 밖에 둡니다. 음악, 효과음, 반복 효과는 시작하면 완료 처리되므로 필요하면 대기를 넣으세요.

장면을 열기 전에 인물 배치

검은 막을 덮고 뒤에서 배경과 인물을 준비한 뒤 막을 걷습니다.

  1. 전환의 페이드 인으로 검은 막을 덮습니다.
  2. 배경을 바꿉니다.
  3. 인물을 등장시키고 페이드와 이동 시간을 0으로 설정합니다. 여러 인물은 동시 실행 그룹을 쓸 수 있습니다.
  4. 전환의 페이드 아웃으로 막을 걷습니다.
막 덮기 → 배경 변경·인물 배치 → 막 걷기 → 대사
인과 아웃은 검은 막의 등장과 사라짐을 뜻합니다. 편집기의 전환 시간은 예시이며 실제 시간은 게임이 정합니다.

검사 결과 읽기

결과 창의 결론을 먼저 보고 문제 위치로 돌아가 고칩니다. 원본 데이터는 기술 상세에 있습니다.

  • 정상: 이번 검사에서 문제를 찾지 못함.
  • 수정 필요: 안내에 따라 내용을 수정.
  • 게임 확인 대기: 오프라인으로 판단할 수 없어 아직 통과가 아님.

F6은 현재 장 검사입니다. 전체 검사는 배포 화면의 배포 검사 및 포장에서 실행합니다.

오래 걸리는 작업은 접고 편집할 수 있습니다. 하단에서 진행이나 결과를 다시 열 수 있고 완료 시 알림도 표시합니다.

용어를 쉽게 설명

양식으로 스토리를 만들 때 코딩 지식은 필요 없습니다.

  • 노드: 스토리의 한 단계.
  • 표식: 사건 발생 여부 기록.
  • 조건 분기: 기록이나 수치로 경로 선택.
  • 미리보기 소재 보관함: 이 컴퓨터에서 보여 줄 그림 모음.
  • 작품 패키지: 내보낸 .lommod 파일.
  • 호스트: 게임에 작품을 불러오는 연결 구성요소.
  • API: 코드에서 쓰는 기능의 입구.
  • Lua: 편집기가 단계에서 생성하는 코드. 보통 직접 쓰지 않아도 됩니다.

저장, 언어, 단축키

Mac은 앱 메뉴의 설정이나 ⌘,, Windows/Linux는 설정이나 Ctrl+,에서 표시 언어를 고릅니다. 작품 번역은 편집 메뉴의 다국어에서 처리합니다.

  • ⌘S / Ctrl+S: 저장.
  • F1: 도움말.
  • F6: 현재 장 검사.
  • F7: 흐름도.
  • F5: Windows 게임 시험.
  • Esc: 도움말이나 알림 창 닫기.
